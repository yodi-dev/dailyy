Kebijakan Privasi Dailyy

Terakhir diperbarui: 10 Oktober 2026

Selamat datang di Dailyy. Privasi Anda adalah prioritas utama kami. Dailyy dirancang sebagai aplikasi pencatat aktivitas personal yang menganut prinsip Local-First (Offline-First), di mana seluruh data Anda disimpan secara privat di perangkat Anda sendiri.

1. Informasi yang Kami Kumpulkan

Dailyy tidak memiliki server basis data terpusat dan tidak mengumpulkan informasi pribadi untuk dijual atau dilacak:

  • Data Log Kegiatan: Catatan nama kegiatan, waktu, dan catatan tambahan Anda hanya tersimpan di memori lokal peramban (LocalStorage/IndexedDB) perangkat Anda.
  • Data Akun Google: Jika Anda memilih untuk menggunakan fitur Cadangan Google Drive, aplikasi akan meminta izin OAuth2 untuk mengautentikasi akun Anda dan mengakses Google Drive pribadi Anda. Kami hanya mengakses foto profil, nama, dan alamat email Anda untuk ditampilkan pada antarmuka aplikasi di perangkat Anda.

2. Penggunaan Google User Data (Google Drive API)

Kepatuhan terhadap Google API Services User Data Policy:
Penggunaan dan transfer data yang diterima dari Google APIs oleh Dailyy ke aplikasi lain akan mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use (Penggunaan Terbatas).

Aplikasi kami hanya meminta izin https://www.googleapis.com/auth/drive.file yang memiliki karakteristik:

  • Dailyy TIDAK membaca, mengedit, atau menghapus file lain di Google Drive Anda.
  • Dailyy HANYA membuat dan memperbarui 1 (satu) file cadangan bernama dailyy-backup.json yang dibuat oleh aplikasi ini sendiri.
  • Data cadangan Anda sepenuhnya milik Anda dan tersimpan di akun Google Drive pribadi Anda.
  • Data Google Anda tidak pernah dikirimkan ke server kami atau pihak ketiga mana pun.

3. Penyimpanan dan Keamanan Data

Seluruh proses enkripsi dan keamanan data selama proses cadangan ke Google Drive ditangani langsung oleh protokol standar HTTPS dan infrastruktur keamanan Google.

4. Menghapus Data atau Memutuskan Sambungan

Anda memiliki kendali penuh atas data Anda kapan saja:

  • Anda dapat memutuskan sambungan akun Google kapan saja melalui tombol "Putuskan Sambungan" di tab Pengaturan Dailyy.
  • Anda dapat menghapus seluruh catatan lokal dengan tombol "Reset Seluruh Catatan" di aplikasi.
  • Anda dapat menghapus file dailyy-backup.json langsung dari Google Drive Anda kapan saja.

5. Hubungi Pengembang

Jika Anda memiliki pertanyaan mengenai kebijakan privasi ini atau penggunaan aplikasi Dailyy, Anda dapat menghubungi kami melalui repositori proyek di GitHub yodi-dev/dailyy.
